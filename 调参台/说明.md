# 电脑端蓝牙调参台

不烧录、不写 EEPROM，在电脑上通过蓝牙实时改车上的运行参数，边跑边看，调直线用。

---

## 一、为什么需要它

调 `GAIN_R` 时一轮要「改宏 → 编译 → 上传 → 插电池 → 跑一圈 → 拔线」，30 秒起步，
一轮只能试一个值。这个工具把一轮压到 2 秒：

```
use R          ← 锁定参数 R
+              ← 加 2，立刻生效
run 2          ← 前进 2 秒自动停，看直不直
+              ← 再加 2
run 2
```

车端会把每次改动后的真实生效值回读过来（`[CAL] L=… R=…`），
所以屏幕上的数字就是芯片里正在用的数字，不是你以为的数字。

---

## 二、一次性准备

### 1. 电脑配对 HC-05

1. 给小车通电，HC-05 的灯**慢闪**（说明没连接、在等配对）
2. 电脑：设置 → 蓝牙和设备 → 添加设备 → 选 `HC-05` → PIN **1234** 或 **0000**
3. 配对完去「更多蓝牙选项 → COM 端口」，会看到一个**出站**端口，例如 `COM6`
4. 设备管理器 → 端口，确认有 `Standard Serial over Bluetooth link (COM6)`

> 一定要用**出站**那个。如果只看到入站，说明配对没完成，删掉设备重新配。

### 2. 拔掉 USB 线

HC-05 和 USB 转串口都接在 D0/D1 上，两个 TX 同时驱动会打架，表现为满屏乱码。
**调参时电脑只走蓝牙，不要插 USB。**

### 3. 手机 App 断开连接

经典蓝牙一个模块只能被一个主机连着。手机还连着的话电脑连不上，
在 App 里点状态块断开，或者关掉手机的蓝牙。

---

## 三、启动

双击 `start.bat`。

```
  可用串口：
    [1] COM9   USB-SERIAL CH340 (COM9)
    [2] COM6   Standard Serial over Bluetooth link (COM6)
  ★ 蓝牙口应该是 COM6，选它
  输入序号或 COM 号（直接回车 = 第 1 个，q = 退出）: 2
```

选完自动连上并发一条 `?` 读回当前参数：

```
[21:52:03] 已打开 COM6 @ 9600
[21:52:03] [校准] 左=256  右=222  速度=110.0%  转弯=…
[21:52:03] [CAL] L=256 R=222 S=1100 FWD=120 TURN=85
[21:52:03] 车端当前：左=256  右=222  速度=1100‰
```

**这行 `[CAL]` 是真正生效的值**，不是源码里的 `#define`。
（EEPROM 里有旧存档时，它会盖掉源码默认值 —— 看到数字和源码对不上就是这个原因。）

## 四、调直线的标准流程

### 情况 A：一直往左跑偏（最常见）

右轮摩擦小、跑得比左轮快，车头被推向左。**降低 `GAIN_R`**：

```
use R
-            ← 222 → 220
run 2
-            ← 220 → 218
run 2
```

到某个值开始往右偏了，就往回加一档，那个临界值附近就是最直的。

### 情况 B：一直往右跑偏

反过来，`+` 加 `GAIN_R`。

### 情况 C：起步瞬间就歪，跑起来反而直

这是**起步同步**问题，不是巡航补偿问题。它由 `TRIM_LEFT` 控制，
**这个宏不能通过串口改**（只能在源码里改完重烧）。调参台帮不上，别白费时间。

### 一次比一组更省事

```
sweep R 212 232 2 3
```

依次试 `R212`、`R214`、`R216`…`R232`，每个值跑 3 秒、停 2 秒，
屏幕会打分隔线告诉你现在是第几组。你只管看哪一组最直，记下来。

跑完一轮通常就能锁定 ±2 的范围。

## 五、命令表

| 命令 | 作用 |
|---|---|
| `f` `b` `a` `d` `s` | 前进 / 后退 / 左转 / 右转 / 停车 |
| `run` / `run 3` | 前进 2 秒 / 3 秒后自动停 |
| `L256` | 左轮增益（150~400） |
| `R222` | 右轮增益（150~400） |
| `S1100` | 全局速度，千分比（600~1400） |
| `T85` | 转弯占空比（60~160） |
| `A78` | 自动模式微调占空比（40~200） |
| `U290` | 自动模式转向角速度 deg/s（60~900） |
| `use R` → `+` `-` | 锁定参数后按步长微调（步长用 `step 5` 改） |
| `sweep R 212 232 2 3` | 自动扫参 |
| `cal` | 读回车端当前参数 |
| `hist` | 看最近 20 次参数变更 |
| `quiet` | 只显示参数/动作行（自动模式刷屏时用） |
| `help` | 帮助 |
| `quit` | 退出（会先发停车） |

其余任何字符串都会**原样发给固件**，所以 `G`（遛狗）、`P`（比赛）、`C90`（云台）、
`V`（左右翻转）、`B1`（蜂鸣）这些都能直接用。

## 六、关于保存

**本工具从不发送 `W`，所以不会写 EEPROM。**

- 串口改的参数只活在 RAM 里，小车一断电就回到源码默认值
- 每一条真正发出去的命令都会写进同目录的 `串口日志_日期_时间.txt`，
  这就是「电脑端的参数记录」
- 调满意了想固化，两条路：
  1. 把值写回源码的 `#define GAIN_RIGHT` 等宏，重新烧录（推荐，可复现）
  2. 自己用串口助手发 `W` 存进 EEPROM（下次上电自动加载，但源码里看不到）

**不要在这个工具里发 `D`** —— 那是擦除 EEPROM 存档、恢复源码默认值。

## 七、常见问题

| 现象 | 原因 |
|---|---|
| 串口列表里没有蓝牙口 | HC-05 没配对 / 电脑蓝牙没开 / 配对后没生成出站端口 |
| `打不开 COMx：拒绝访问` | 被串口助手、Arduino IDE 或手机占着 |
| 连上了但没反应、满屏乱码 | 波特率不对（用 `-Baud 38400` 试），或者 USB 线还插着 |
| 发了 `R220` 但 `[CAL]` 数字没变 | 超出范围（150~400）被固件忽略；或车端没收到（看日志有没有 `TX>` 和回读） |
| 跑一次就断 | HC-05 供电跌落，见下 |

HC-05 供电不足时（电机启动瞬间拉垮 5V）会自己复位，串口直接消失。
调参台会打印发送失败并关闭端口，重新插一次即可。根本解决是给 HC-05 单独稳压供电。

## 八、和手机 App 的关系

同一个 HC-05，**二选一**：

- 用手机 App 遥控/跑自动模式 → 手机连
- 用电脑调参 → 电脑连

两边同时连不上，别浪费时间。调完参数想用手机验证，先关调参台（`quit`），再用手机连。
